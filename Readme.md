# FriendsLink

这是一份 vibe coding 产物，所以除了这个 md 之外，代码都是 Claude Code 写的。

## 介绍

FriendsLink 是基于 Wordpress 的一个友链管理和显示插件。其提供了一个简单的方式来轻松的添加和管理友链。

## 功能

友链具备如下可选项：

- 友链名称
- 友链 URL
- 图标显示
- 友链描述
- 友链分组
- 友链排序
- 友链标签

## 安装及使用

请下载 Release 中的 zip 文件，解压后将其中的文件夹上传到 Wordpress 的插件目录中。然后在 Wordpress 后台的插件管理界面中启用 FriendsLink 插件。启用后，您可以在 Wordpress 后台的“友链管理”菜单中管理您的友链。

要在文章中添加友链，请使用以下短代码：

```
[friendslink]
```
